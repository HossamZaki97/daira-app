# Cairo font files

يستخدم التطبيق ملفات Cairo المحلية التالية، ولا يحمّل أي خط عبر الشبكة:

- `Cairo-Regular.ttf` (400)
- `Cairo-SemiBold.ttf` (600)
- `Cairo-Bold.ttf` (700)
- `OFL.txt` — SIL Open Font License 1.1

المصدر: عائلة Cairo المنشورة عبر Google Fonts ومستودع `google/fonts/ofl/cairo`. ينص ملف الترخيص المرفق على: Copyright 2009 The Cairo Project Authors، تحت SIL Open Font License 1.1.

الأوزان مسجلة في `pubspec.yaml` كـ400 و600 و700، وتُحمّل محليًا دون خدمة خطوط خارجية.
